# パンケーキで月へ行こう！

右から流れてくるパンケーキに飛び乗り、積み上げながら高みを目指す2Dアクションゲームです。ジャンプのタイミングを合わせて、目標枚数の積み上げに挑戦します。

## 作品情報

| 項目 | 内容 |
| --- | --- |
| 開発環境 | Unity |
| 使用言語 | C# |
| ジャンル | 2Dアクション |
| 制作体制 | 個人制作を中心に開発。サウンドの挿入は他の人が担当 |
| リポジトリ | [SagoYukina/Pancak_Moon](https://github.com/SagoYukina/Pancak_Moon) |

## 遊び方

1. モードを選択してゲームを開始します。
2. 右から流れてくるパンケーキに、タイミングを合わせてジャンプします。
3. パンケーキに着地すると、その場で停止して積み上がり、次のパンケーキが出現します。
4. 横から接触するとライフが減ります。接触を避けながら、さらに上を目指します。

### 操作方法

| 操作 | 入力 |
| --- | --- |
| ジャンプ | Spaceキー、またはマウスの左クリック |

### ゲームモード

目標枚数が20枚・50枚・100枚のモードに加え、積み上げを続けられるエンドレスモードを用意しています。

## 実装した機能

- パンケーキへの着地と横からの接触の判定
- 着地したパンケーキの停止・積み上げ処理
- 次のパンケーキの自動生成
- ライフ・スコア・クリアの管理
- プレイヤーの上昇に合わせたカメラ追従
- `PlayerPrefs`によるモード設定の引き継ぎ

## 制作上の工夫

同じパンケーキへの接触でも、上に乗れた場合と横からぶつかった場合で結果を分けています。ジャンプのタイミングが積み上げの成否につながる仕組みです。
また、積み上げに合わせてカメラを上へ追従させ、高さが増してもプレイを続けられるようにしています。
